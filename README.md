Philosophy & Design Principles
This codex is built on a few core ideas:

Modularity
Small, self‑contained projects with clear boundaries.

Extensibility
Everything should be easy to expand, fork, or repurpose.

Clarity over cleverness
Readable code beats “smart” code.

Playfulness
Engineering is fun — especially when mixed with worldbuilding.
