**Dungeons and dragons combat simulator**

This program utilizes the rust programming language to simulate simplified battles between various
monsters in dungeons and dragons.  It works by a command-line entry that requires:

1. The data path to the monster data
2. The path to the 1st team (stored in json)
3. The path to the second team
4. The number of battles to simulate.

When complete, the software will show the winning sides and appropriate details therein.
